# Исторические лицензии (эра ≤ v0.17.7)

`LICENSE-MIT` и `LICENSE-APACHE` применялись к версиям poler-engine **до
v0.17.7 включительно** (эра двойного MIT/Apache-2.0-лицензирования).

Начиная с **v0.22.0** движок и все крейты workspace распространяются под
**POLER Custom Source-Available & Modification Disclosure License v1.0**
(модель Unreal Engine EULA) — см. корневой `LICENSE.md` и практическую
сводку `TERMS.md`.

Файлы сохранены здесь для истории и для прав, полученных третьими лицами
на производные версии ≤ v0.17.7 в тот период. На текущие версии они **не
распространяются**.

> репозитория — корневой `LICENSE.md`. Файлы в этом каталоге — исторический

> из корня (2026-10-22), чтобы корневая `LICENSE*`-маска больше не
> детектировалась как «MIT».
